================================================================================
DATA FLOW ARCHITECTURE
================================================================================

INPUT SOURCES:
  Instagram (@merzy.eg) → Instagram Scraper
  Facebook (Page ID) → Facebook Scraper
  Talabat (Restaurant) → Talabat Scraper

RAW OUTPUT:
  scraped-data/raw/instagram-posts.json
  scraped-data/raw/facebook-posts.json
  scraped-data/raw/talabat-menu.json

PROCESSING PIPELINE:
  Raw JSON
    ↓
  Transform Data (convert to MERZY formats)
    ↓
  Download & Cache Images (local storage)
    ↓
  Deduplicate Posts (remove duplicates)
    ↓
  Validate Data (comprehensive checks)
    ↓
  Generate TypeScript Files
    ↓
  FINAL OUTPUT:
    src/app/core/data/merzy-social.ts
    src/app/core/data/menu.ts

================================================================================
QUICK START (5 MINUTES)
================================================================================

1. INSTALL DEPENDENCIES:
   npm install axios cheerio

2. CREATE CONFIGURATION:
   Create .env.scraper file with:
   - INSTAGRAM_USER=@merzy.eg
   - FACEBOOK_PAGE_ID=61583371166412
   - TALABAT_RESTAURANT_ID=1102357
   - OUTPUT_DIR=./scraped-data

3. RUN FULL PIPELINE:
   npm run scrape:full

4. VERIFY OUTPUT:
   - Check src/app/core/data/merzy-social.ts
   - Check src/app/core/data/menu.ts
   - Check scraped-data/images/
   - App auto-reloads with new data ✅

================================================================================
SUPPORT & TROUBLESHOOTING
================================================================================

COMMON ISSUES:

Q: "Cannot find module 'axios'"
A: Run: npm install axios cheerio

Q: "Instagram 429 Too Many Requests"
A: Rate limited. Wait 1 hour or use different IP.

Q: "Facebook token invalid"
A: Refresh token in Graph Explorer (developers.facebook.com)

Q: "No images downloading"
A: Check scraped-data/images/ exists and is writable

Q: "TypeScript files not generating"
A: Verify raw JSON files exist in scraped-data/raw/

FOR MORE HELP:
  - Check CONFIGURATION.md troubleshooting section
  - Run with DEBUG_SCRAPER=true for verbose output
  - Check raw JSON in scraped-data/raw/ for inspection
  - Review error messages in console
