╔══════════════════════════════════════════════════════════════════════════════╗
║                          QUICK START COMMANDS                               ║
╚══════════════════════════════════════════════════════════════════════════════╝

  npm run scrape:full           → Full pipeline (scrapers + processor)
  npm run scrape:instagram      → Instagram only
  npm run scrape:facebook       → Facebook only
  npm run scrape:talabat        → Talabat only
  npm run scrape:all            → All scrapers (no processor)
  npm run process:data          → Process existing raw data

  Debug modes:
  DEBUG_SCRAPER=true npm run scrape:full
  DEBUG_PROCESSOR=true npm run process:data

  Test mode (no network):
  ts-node scripts/orchestrator.ts --test

    • Detailed error reporting

    • Log all errors
